# Google Homepage Clone 
A responsive, static recreation of the Google homepage using **HTML5 and CSS3 only**. Built for a beginner web-development internship assignment.

## Features
- Multicolour Google-style wordmark created with HTML and CSS
- Responsive top navigation and account button
- Rounded search field with decorative search, voice, and image icons
- Search action buttons (visual only; search is not implemented, as permitted by the task)
- Language links and responsive footer
- Keyboard focus styling and mobile-friendly layout

## Run locally
1. Extract the ZIP.
2. Open this folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the **Live Server** VS Code extension and choose **Open with Live Server**.

## Files
- `index.html` — page structure and inline decorative SVG icons
- `style.css` — layout, colors, hover states, and responsive breakpoints

## Notes
This is an educational UI recreation. It is not affiliated with or endorsed by Google. The search box and buttons are visual demonstrations, not a working search engine.
